>
> 过程：
> 1. **数据生成与清洗**：按真实企业公开信息校准业务口径，用固定随机种子生成 3.5 年数据（48 SKU / 1,500 客户 / 2,401 订单 / 5,982 付款 / 189 售后）；清洗产出 orders_clean / item_flat / customer_rfm 三张宽表，交付字段缺失按业务属性保留。
> 2. **指标体系与分析**：建立增长 / 渠道 / 品类 / 客户价值(RFM) / 交付履约 / 售后六套指标。发现抖音 + 老客户转介是零成本增长引擎（3 年成交额 2.3 倍）；收入 53% 依赖不锈钢门；装企合作客单最高 ¥3.6 万；准时率 79.7%、铜门交付周期 58 天最长。
> 3. **可视化**：Streamlit 交互看板（5 视图 + 动态结论）+ Plotly，配色通过色盲安全校验。
> 4. **建模（进阶）**：XGBoost 月度销售预测、客户分群与复购预测，输出特征重要性（详见 notebook 03）。
>
> 结果：沉淀 8 张原始表 + 3 张分析宽表 + 3 本可执行 notebook + 交互看板 + 数据字典 + 分析报告，全链路可一键复现（固定 seed）。

## 三、面试 2 分钟完整故事（问题→方法→结论→效果）

> **为什么做这个项目（问题）**
> 我想找数据分析岗，需要一个能体现「从业务问题出发、走完整个闭环」的作品集。所以我挑了一个足够小、但业务关系真实的场景：一家定制门厂——它没有像样的报表，老板靠直觉经营。我用数据回答他一个真实的问题：**「一个小厂，怎么用最低的成本（一个展厅 + 一条抖音）把单子做起来、把钱赚稳？」**
>
> **怎么做（方法）**
> 第一步建数据。我按行业公开信息（产品线、区域、经营模式）校准业务逻辑，用固定随机种子生成了 3.5 年、1,500 客户 / 2,401 订单 / ¥6,000 万营收的模拟数据，保证可复现、可审计。
> 第二步清洗建指标。产出三张分析宽表：订单主表、订单明细、客户 RFM 分群；明确口径（有效订单=剔除取消、准时率=已完成订单内按时占比等）。
> 第三步分析。围绕增长、渠道、品类、客户价值、交付售后五个子题展开。
> 第四步建模。用 XGBoost 做月度销售预测与复购预测，用 KMeans 交叉验证 RFM 分群。
> 第五步落地。做成 Streamlit 交互看板，让老板筛选年份/渠道/品类，结论随筛选动态更新。
>
> **发现了什么（结论）**
> ① 增长引擎是抖音 + 老客户转介，几乎零广告费，3 年成交额 2.3 倍。② 收入 53% 靠不锈钢门、前 3 品类约 8 成——品类过于集中，需要「不锈钢跑量 + 铜门做利润」组合。③ 装企合作客单价 ¥3.6 万全渠道最高、贡献 30% 收入，是高价值客户（70%）的主要来源，值得重点经营。④ 交付准时率只有 79.7%，铜门周期最长 58 天，是运营短板。⑤ 213 名高价值客户贡献 41% 收入，是利润基本盘。
>
> **带来什么效果（效果）**
> 每个结论都落到可执行动作：短视频内容标准化 + 投流放大、转介绍激励、重点服务 2-3 家装企、下单给足交付预期并在关键节点对客户可见、高价值客户专属权益。等于给小厂做了一次免费经营体检，也完整展示了我的数据能力闭环。
